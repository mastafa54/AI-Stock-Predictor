# 📈 AI-Powered Stock Market Price Prediction Website

An AI-powered financial platform that predicts stock prices using **Python & Prophet**, features interactive charts, and includes an AI financial chatbot. Built with **React**, **Node.js**, **MongoDB**, and **FastAPI**.

---

## 🚀 Key Features

* **Stock Price Prediction:** Time-series forecasting for future stock trends using Meta's Prophet model.
* **Interactive Financial Charts:** Visual stock market performance and prediction curves using Recharts.
* **AI Financial Assistant:** Smart financial chatbot integrated with OpenAI API for instant market analysis.
* **User Authentication & Watchlist:** Secure login (JWT & bcrypt) to save and track favorite stocks.

---

## 🛠️ Tech Stack & Architecture

### **Frontend**
* **Framework:** React.js (Vite)
* **Styling:** Tailwind CSS
* **Charts:** Recharts / Chart.js
* **HTTP Client:** Axios

### **Backend**
* **Runtime:** Node.js
* **Framework:** Express.js
* **Database:** MongoDB & Mongoose
* **Security:** JWT (JSON Web Tokens), bcryptjs

### **AI & Data Service**
* **Language:** Python
* **API Framework:** FastAPI
* **Forecasting Model:** Prophet
* **Financial Data Source:** yfinance
* **Data Handling:** Pandas, NumPy
